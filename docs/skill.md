# 財務分析ツール — 機能・技術スキル一覧

このドキュメントはClaude Projectのカスタム手順補足用です。  
ツールが「できること」と「使っている技術」をまとめています。

---

## できること（機能一覧）

### ファイル読み込み

| 形式 | 拡張子 | 特記事項 |
|------|--------|---------|
| PDF | `.pdf` | テキストPDFのみ（スキャン不可）。△▲/(xxx)の負数表記に対応 |
| Excel | `.xlsx` `.xls` `.xlsm` | シート自動選択。千円・百万円単位に対応 |
| Word | `.docx` | 表形式優先、段落テキストにもフォールバック |
| Google Drive | 共有URL | PDF/スプレッドシート/ドキュメントのURLを直接指定可 |

### 財務指標の自動計算

| カテゴリ | 指標 |
|----------|------|
| 収益性 | 売上総利益率・営業利益率・純利益率・ROA・ROE・EBITDAマージン |
| 安全性 | 流動比率・当座比率・自己資本比率・負債資本比率・ICレシオ |
| 効率性 | 総資産回転率・棚卸資産回転率・売掛金回収日数 |
| 成長性 | 売上高・営業利益・純利益・総資産の各成長率（前期比較） |
| CF | 営業CFマージン・フリーキャッシュフロー・CF/有利子負債 |

### 評価・レポート

- 各指標に対してコメントを自動生成（★評価付き）
- 総合スコア（0〜100点）を算出
- テキスト形式 / Markdown形式でレポート出力
- ファイルへの保存またはダウンロード

### 実行環境

| 方法 | 対象ユーザー | 特徴 |
|------|-------------|------|
| Google Colab | タブレット・スマホ | Drive直接マウント、番号選択でファイル指定 |
| Streamlit WebUI | PC | ブラウザからドラッグ&ドロップ |
| CLIスクリプト | PC（ターミナル） | バッチ処理・自動化向け |

## 技術スタック

### 言語・フレームワーク

| 技術 | バージョン | 用途 |
|------|-----------|------|
| Python | 3.9以上 | メイン言語 |

### ライブラリ

| ライブラリ | バージョン | 用途 |
|-----------|-----------|------|
| PyMuPDF (fitz) | ≥1.23 | PDF テキスト・座標抽出 |

| python-docx | ≥1.0 | Word (.docx) 読み込み |
| requests | ≥2.31 | Google Drive 公開ファイルDL |

### 設計パターン

| パターン | 適用箇所 |
|----------|---------|
| dataclass + `__post_init__` | 財務諸表の自動計算（models.py） |
| Strategy パターン | ローダーの拡張子別切り替え（file_loader.py） |
| ゼロ除算ガード | `_safe_divide()` + `_pct()` ヘルパー（ratios.py） |
| 座標ベース抽出 | 日本語PDFのラベル・数値マッチング（pdf_loader.py） |
| 定数マップ | `KEYWORD_MAP` で日本語科目名を内部フィールドに変換 |

## ソースコード構成

```
financial_analysis/
├── models.py          # IncomeStatement / BalanceSheet / CashFlowStatement
├── ratios.py          # 財務比率計算（5カテゴリ）
├── analyzer.py        # 評価コメント + 総合スコア（0〜100）
├── report.py          # テキスト / Markdown レポート生成
├── file_loader.py     # 統合ローダー（拡張子で自動振り分け）
├── pdf_loader.py      # PyMuPDF ベースのPDFローダー
├── excel_loader.py    # openpyxl ベースのExcelローダー
├── word_loader.py     # python-docx ベースのWordローダー
└── google_drive_loader.py  # Google Drive URL対応ローダー
```

## 科目名認識キーワード（主要）

ファイル内の科目名がこれらのいずれかと一致・部分一致すれば自動認識されます。

| 科目 | 認識されるキーワード |
|------|---------------------|
| 売上高 | 売上高、売上、営業収益、売上収入、収益合計 |
| 売上原価 | 売上原価、製造原価、原価合計 |
| 売上総利益 | 売上総利益、粗利、粗利益 |
| 販管費 | 販売費及び一般管理費、販管費、販売費、一般管理費 |
| 営業利益 | 営業利益、営業損益、営業損失 |
| 経常利益 | 経常利益、経常損益、経常損失 |
| 当期純利益 | 当期純利益、当期純損失、当期利益、純利益 |
| 法人税等 | 法人税、法人税等、法人税・住民税及び事業税 |

## 既知の制限

| 制限 | 内容 |
|------|------|
| スキャンPDF不可 | 画像PDFは認識できません。テキスト選択できるPDFが対象 |
| `.doc`非対応 | 旧Word形式。`.docx`に変換して使用 |
| プロキシ環境 | 社内ネット等からのGoogle Drive直接DLは403エラーになる場合あり |
| 前期比較 | 成長率は前期データを手動で渡した場合のみ算出可能 |
| 貸借対照表・CF | Colabノートブック版では損益計算書のみ対応（ライブラリ版は全対応）|
