# 機能追加ロードマップ

今後追加・改善したい機能をまとめています。  
優先度: 🔴 高 / 🟡 中 / 🟢 低

---

## 近い将来（次のバージョン）

### 🔴 前期比較のUI対応
**概要:** Colabノートブック・Streamlit で前期データを入力できるようにする。  
現状は成長率が常に「データなし」になる。

**実装方針:**
- Colabセル⑤に `PREV_FILE_NUMBER` 変数を追加
- StreamlitのサイドバーにPDF/Excelの2ファイルアップロード欄を追加

---

### 🔴 科目名が認識できない場合の手動マッピング
**概要:** 独自の科目名（「月商」「仕入高」等）を認識できない場合に、ユーザーが手動でマッピングを設定できる。

**実装方針:**
- Colabでマッピング辞書を入力できるセルを追加
- `CUSTOM_KEYWORDS = {'月商': 'revenue', '仕入高': 'cost_of_goods_sold'}` のような設定

---

### 🟡 複数期間の比較レポート
**概要:** 2〜5期分のデータを並べて比較するレポートを生成する。

**実装方針:**
- `FinancialData` のリストを受け取る `ComparisonAnalyzer` クラスを追加
- Markdownテーブルで年度別に指標を横並び表示

---

## 中期的な機能

### 🟡 グラフ・チャート出力
**概要:** 財務指標の推移をグラフで表示する。

**実装方針:**
- Colabでは `matplotlib` を使用（インストール不要）
- Streamlit では `st.bar_chart` / `st.line_chart` を活用
- 売上高・営業利益・純利益の棒グラフ
- 各指標の業界平均との比較レーダーチャート

---

### 🟡 Excel出力対応
**概要:** 分析結果をExcelファイルで出力する。

**実装方針:**
- `openpyxl` を使い、指標・コメント・グラフを1ファイルにまとめる
- Streamlit でダウンロードボタンを追加

---

### 🟡 Colabで複数期を一度に指定
**概要:** セル⑤で「当期ファイル番号」と「前期ファイル番号」を両方指定できる。

```python
CURRENT_FILE  = 2   # 当期
PREVIOUS_FILE = 1   # 前期（成長率算出に使用）
```

---

### 🟡 Googleスプレッドシートへの直接書き込み
**概要:** 分析結果をGoogleスプレッドシートに自動入力する。

**実装方針:**
- `gspread` ライブラリを使用
- Colab環境でサービスアカウント不要（`google.colab.auth` で認証）

---

## 長期的な機能

### 🟢 貸借対照表・CFのColab対応
**概要:** Colabノートブック版でも貸借対照表とキャッシュフロー計算書を読み込む。  
（現在はPythonライブラリ版のみ対応）

---

### 🟢 業界別ベンチマーク比較
**概要:** 業界の平均指標と比較してコメントする。

**実装方針:**
- 業界コード別の平均値データベース（JSONファイル）を用意
- 「製造業平均と比べて営業利益率が高い」等のコメントを追加

---

### 🟢 OCR対応（スキャンPDF）
**概要:** 画像PDFにもOCRを適用して数値を抽出する。

**実装方針:**
- `pytesseract` または Google Vision API を使用
- Colabでは Google Vision API が利用しやすい

---

### 🟢 CI/CD 自動化
**概要:** プッシュ時にテストを自動実行し、失敗したらマージをブロックする。

**実装方針:**
- GitHub Actions の設定ファイル (`.github/workflows/test.yml`) を追加
- `pytest tests/ -v` を自動実行

---

### 🟢 スキャン表の認識改善
**概要:** 罫線で区切られた表形式のPDFで、列ずれを自動補正する。

---

## 実装しないこと（スコープ外）

| 機能 | 理由 |
|------|------|
| 財務予測・将来推計 | 本ツールは実績分析に特化 |
| 株価・市場データ連携 | スコープが大きく複雑になるため |
| 多言語対応（英語等） | 日本語の財務書類に特化 |
| クラウドホスティング | セキュリティ要件が別途必要 |
