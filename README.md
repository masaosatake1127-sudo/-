| 機能 | 説明 |

## セットアップ

### 必要環境

- Python 3.10 以上
- pip

### インストール

```bash
pip install streamlit anthropic
```

または `requirements.txt` から一括インストール:

```bash
pip install -r requirements.txt
```

### APIキーの設定（AI講師を使う場合）

AI講師機能には [Anthropic API キー](https://console.anthropic.com/) が必要です。

**Mac / Linux**
```bash
export ANTHROPIC_API_KEY="sk-ant-xxxxxxxxxxxx"
```

**Windows (コマンドプロンプト)**
```cmd
set ANTHROPIC_API_KEY=sk-ant-xxxxxxxxxxxx
```

**Windows (PowerShell)**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-xxxxxxxxxxxx"
```

> APIキーを設定しなくても、学習・練習問題機能は利用できます。

## 起動方法

```bash
# リポジトリのルートで実行
streamlit run math_tutor_app.py
```

ブラウザが自動的に開かない場合は手動でアクセス:

```
http://localhost:8501
```

## 画面説明

### ホーム
- 全単元の学習状況（学習済み/未学習）と正答率を一覧表示
- ワンクリックで各単元へ移動

### 単元学習
タブ構成:

```
📖 学習内容  |  各セクション名 …  |  📐 重要公式  |  ✏️ 練習問題へ
```

1. **学習内容** — セクション一覧と概要
2. **各セクションタブ** — 詳細説明・例題（Markdown + LaTeX）
3. **重要公式** — 公式を LaTeX で整理
4. **練習問題へ** — 問題数を確認してスタート

### 練習問題
- 問題はランダム順で出題
- 選択肢を選んで「答え合わせ」→ 正誤判定 → 解説表示
- 「スキップ」で次の問題へ
- 全問終了後に振り返り一覧を表示
- 「🤖 AI講師に質問する」ボタンで該当問題をチャットに自動入力

### AI講師チャット
- クイックスタートボタンから頻出質問を選べる
- 会話履歴をセッション中保持
- プロンプトキャッシュ対応（API コスト削減）

## 対応単元と問題数

| アイコン | 単元 | 問題数 | 主な内容 |
|---------|------|--------|---------|
| 🔢 | 式の計算 | 6問 | 単項式/多項式の加減乗除、代入 |
| ⚖️ | 連立方程式 | 4問 | 加減法・代入法・文章題 |
| 📈 | 一次関数 | 5問 | 傾き・切片・2点から式・グラフ |
| 📐 | 図形の性質 | 4問 | 合同条件・二等辺三角形・平行四辺形 |
| 🎲 | 確率 | 4問 | 基本確率・余事象・サイコロ・球 |
